# Portafolio Básico

Este es un proyecto realizado como parte del curso **"Programación Web Desde Cero"** en la plataforma **Egg Live**, finalizado en septiembre de 2024.  
El objetivo fue aplicar los conceptos básicos de desarrollo web para construir un portafolio personal sencillo.

## 🚀 Tecnologías utilizadas
- **HTML**  
- **CSS**  
- **JavaScript**

## 📂 Contenido
- Página principal con presentación personal.  
- Header con secciones para **Trabajos**, **Servicios** y **Contacto** pensadas para expandir el proyecto de forma autónoma.  

## 🎯 Objetivo del proyecto
Practicar los fundamentos de la programación web, especialmente:  
- La estructura semántica con **HTML**.  
- El diseño con **CSS**.  
- La interactividad básica con **JavaScript**.  

## 📝 Notas
